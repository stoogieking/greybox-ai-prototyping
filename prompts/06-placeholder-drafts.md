# 06 · Crude drafts at the right size

Rough placeholders at the real size show proportions and how each piece fits. Then you redraw every one by hand. These prompts avoid copying anyone else's art: no artist names, no studio or game names, no "in the style of".

---

## Layout drafts (for capsules, posters, store pages)

```
Make a rough layout draft of [ASSET, e.g. a Steam main capsule] at exactly [WIDTH×HEIGHT] px.

Subject: [describe the scene in plain visual terms: who, doing what, pose, camera angle].
Style, described only in visual terms: [e.g. solid black silhouettes on terracotta orange, thin incised lines for detail, comic speed lines].
The only style reference allowed is public-domain historical art: [e.g. ancient Greek black-figure pottery]. Don't imitate any living artist, studio, game or film.

Leave [where] clear for the title logo. Use only the title as text.
Build it from simple shapes so it reads as a draft, not finished art.
```

## Sprite and model drafts

```
From the asset list, make a crude placeholder for [ASSET NAME] at its real in-game size ([SIZE]).
Flat colours, simple shapes, clear silhouette. Mark the pivot point.
It only has to show proportions and fit; it will be redrawn by hand.
```

## If you use an image generator

- Pick one trained on licensed data, and check what the tool currently says about its training sources.
- Never put artist or studio names in the prompt, or tags like "trending on ArtStation".
- Treat the result as a composition sketch and repaint it yourself.
- Keep a note of what was generated. Steam asks you to disclose AI-generated content that ships in the game or appears in marketing, such as store art; itch.io has a generative-AI field with a graphics tag. A draft you fully repaint by hand is no longer in the game, but keep the note anyway.
