# 07 · README for a finished prototype

```
Write a README.md for [PROTOTYPE NAME], attached. Structure:

1. Name and a one-line pitch in bold
2. Badges: license and status
3. A screenshot line: ![alt text](docs/images/[file].png), with a real description as alt text
4. One short paragraph: what it is and the question it answers
5. Play link: [itch.io or GitHub Pages URL]
6. Contents list
7. What is in it (the loop, enemies, levels), using tables where things are compared
8. Controls table
9. How it works: a mermaid flowchart of the loop, then a table of the juice effects (Effect | What it does | Why it matters)
10. Tuning panel: what each group of sliders does
11. Limitations: honest, including how it was tested and what hasn't been tested
12. Privacy: what it stores and what it downloads
13. For developers: file structure, where the data tables are
14. Copyright/license and credits, including "developed with the help of Claude"

Plain words, short sentences. Only describe features that exist in the code. Don't claim anything was playtested unless I tell you it was.
```
